Disneyland Paris: Quoting Steps

How to find the right rate, add taxes, and build a Disneyland Paris quote so the correct Price Point is applied when we book.
Quick Reference 1. Availability 2. Season 3. Contract Rate 4. Taxes 5. Build in TS Price Point Key Final Check
🏰

Disneyland Paris quotes are built as a shell, so the supplier relies on us to tell them which rate to apply. The rate we quote is identified by two codes: the Rate Code (RC) shown on the calendar, and the matching Price Point (PP) in the contract. Following these five steps in order, and noting both codes on every quote, means the rate the client sees is the rate we book.

Quick Reference: Terms Used

These short forms appear throughout the calendars, contracts and TS.
RC
Rate CodeShown on the Availability calendar, and at the top of each net sheet (tab) in the contract.
PP
Price PointThe contract's price level. PP numbers do not match RC numbers, so always check both.
LOS
LOS calendarThe Availability calendar used for the Standard Package Rates contract.
TS
TSWhere the quote shell is built, the prices are added, and the Financial tab is checked.
A
Part A

Find What Is Available

1

Check the Availability Calendar

Start with the calendar that matches the type of rate you are quoting:

Quoting
Standard Package Rates contract→ use the LOS calendar
Quoting
Specials→ use the Specials calendar

Make a note of the following as they show on the calendar:

  • Hotel
  • Room type
  • Rate Code (RC)
💡
Keep this note handyThe Rate Code you write down here is what tells you which contract sheet to open in Step 3.
2

Check the Package Calendar for the Season

Refer to the Package calendar to confirm which season applies to the travel dates you are quoting:

Value Moderate High Very High

You will need the season to find the correct rate column in the contract.

B
Part B

Find the Rate

3

Find the Package Rate in the Contract

Open the contract that matches your calendar (Standard Package Rates or Specials) and check that your booking and travel dates fall within its validity.

  1. Use the net sheets (tabs) only.
  2. Open the sheet that matches your Rate Code from the Availability calendar (for example RC1, RC2, RC3).

    The RC numbers do not match the PP numbers, so check the top of each sheet to confirm you have the right Rate Code.

  3. Note the Price Point and Rate Code together. You will add this to Free Text later, and you will need it for the Supplier Request form.

    Written like this:

    RC3/PP4
  4. Find your hotel and room type by scrolling up and down the sheet.
  5. Go to the season you confirmed in Step 2 (Value, Moderate, High and so on).
  6. Select the package rate you need. Rates are per person, in EUR.
👀
Take your time on the columnsThe sheets are wide, so keep your eye on the right column as you move across from the room type to the rate.
C
Part C

Add Taxes and Build the Quote

4

Add the Taxes

Refer to the Tax sheet (saved in SP) and match up the package and hotel.

  • Taxes are per person, per night.
  • Because of the way TS is linked to taxes, they need to be added separately.
5

Build the Quote in TS

  1. Use the shell in TS and add the prices, including taxes.
  2. Do a manual calculation, then double check the rate is correct against the Financial tab in TS.
  3. Add to Free Text: the RC code, the Price Point, and which contract you used. This way you always know which code was quoted, and what to ask DLP to apply when you book.

    For example:

    RC3/PP4
  4. Add the RC and PP to your Supplier Request. As this is a shell, DLP needs us to tell them which RC and PP to apply.

Why the Supplier Request mattersIf we don't tell DLP which Price Point to apply, they will automatically apply PP6 (RC1), which is the most expensive rate. Adding the RC and PP to every Supplier Request keeps the booking in line with the quote.
✓

Final Check Before Sending

  • I used the right calendar (LOS for Standard Package Rates, Specials calendar for Specials)
  • I confirmed the season on the Package calendar
  • Booking and travel dates fall within the contract validity
  • I used the net sheet whose Rate Code matches the calendar
  • The rate is per person in EUR, from the correct season column
  • Taxes are added separately, per person per night
  • My manual calculation matches the Financial tab in TS
  • RC, PP and contract name are in Free Text (for example RC3/PP4)
  • RC and PP are on the Supplier Request
